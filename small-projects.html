Small Projects

Smaller projects I've worked on in the past — some for coursework, others built for myself.

Motor Control

Controlled the position of a brushed DC motor using an encoder. A DRV8833 H-bridge and an INA219 current sensor regulate the current delivered to the motor, while a PID control system calculates the current needed to reach a desired position. Position arrays are delivered from a Python client and plotted against the actual position for tuning.

IMU Mouse

Created an IMU mouse using a Raspberry Pi Pico and an IMU sensor. Pitch and yaw are published from the Pico over USB HID communication, and the IMU's acceleration data drives the mouse position.

Push Button Flappy Bird

Used Pygame Zero to build the graphics and mechanics of Flappy Bird. Button input is streamed into the game from a Raspberry Pi through the serial monitor and a Python client.

Bike Brake Caliper Design

Designed and tested bike brake calipers in Siemens NX. An independent solo project, with the bulk of the time spent in CAD and FEA.
