// Atomic Industries

Cooling Channel Test Rig

Atomic Industries uses conformal cooling channels generated by simulation software. The intern team designed and built a test rig to validate cooling channel performance. It collects data on key channel characteristics like pressure drop, flow rate, and temperature.

C/C++ ESP32 Embedded Systems

Objective

Atomic Industries' topology-optimized 3D-printed conformal cooling channels offer better mold performance than conventional drilled waterlines. There are concerns that their thin, branching geometry will accumulate mineral, rust, and dirt deposits and clog over time. The project's goal was to build a test rig that could compress months of real-world scale buildup into weeks, generating real deposition data to de-risk adoption for customers and validate CFD assumptions.

Approach

Built a closed-loop system that pumps deliberately hardened water through 9 parallel test lines, each fitted with a distinct channel geometry (conformal, drilled baseline, and isolated feature designs). A custom 60-channel data acquisition system and PCB (ESP32 with dual I²C ADC buses) continuously logs flow, pressure, and temperature per line, while a calibrated TDS sensor tracks calcium leaving solution in the reservoir as a real-time proxy for total scale accumulated on the channel walls.

Outcome

The result is a modular, self-contained rig — assembled on a T-slot aluminum chassis with quick-disconnect channel mounts. Automated to run continuously, collecting pressure-drop, flow, and temperature data as scale accumulates across multiple channel geometries. The rig doubles as a general-purpose test bench for validating CFD models against physical geometries and generates a dataset that can eventually feed scale-prediction models.
