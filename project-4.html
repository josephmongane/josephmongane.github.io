Haptic Paddle

Advanced mechatronics final project: a haptic paddle that controls a moving object in a force field, with real-time force feedback.

Electronic Prototyping KiCad C++ Electronic Hardware CAN

Objective

Create a haptic paddle with real-time force feedback that simulates moving an object through a virtual environment, controlling the force felt by the user with a closed-loop force control system and a servo motor.

Approach

Built a force controller around a force gauge, driving toward the desired force at each position. An AS5600 encoder tracks the paddle's polar position, from which the desired current is calculated against the positional force field. That current is communicated over CAN polling to an STM32 current control system built around a DRV8833 H-bridge and an INA219.

Outcome

Produced a haptic paddle with near-real-time force feedback. The main obstacles to full functionality were latency in the desired-force signal and unstable tuning of the force controller.
