// Baja SAE

ECVT Manual Controls

A driver-controlled tuning system for Northwestern Baja SAE's electronic continuously variable transmission (ECVT), built as part of the club's powertrain subsystem.

Electronic Prototyping KiCad C++ Electronic Hardware

Objective

Create a robust, driver-operated manual tuning switch that adjusts ECVT tuning between max torque, max power, and discrete sheave positions, with a design able to reliably lock into those discrete positions.

Approach

Modeled and 3D-printed a rotary detent switch with adjustable cockpit mounting, designed a custom PCB in KiCad with footprints matched to the selected components, and modified the existing C++ control logic to tune the PID loop for maximum torque and power based on engine RPM.

Outcome

Delivered a functional, driver-accessible ECVT tuning switch that integrates custom electronics and firmware into the vehicle's powertrain control system.
